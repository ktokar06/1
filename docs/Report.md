# Отчёт о тестировании

## Краткое описание

Проведено автоматизированное тестирование функциональности оплаты и покупки в кредит на сайте http://localhost:8080. Протестированы позитивные и негативные сценарии заполнения формы с данными банковской карты. Проверка результатов выполнялась через UI (сообщения валидации полей).

## Обнаруженные дефекты

### Баг №1: Владелец из одного слова проходит валидацию

**Сценарии:** NEG-PAY-HOLDER-ONE-WORD-01, NEG-CREDIT-HOLDER-ONE-WORD-01

**Описание:** Поле «Владелец» принимает значение из одного слова (например, "Ivan") без фамилии. Форма отправляется успешно.

**Ожидаемый результат:** Под полем «Владелец» должно отображаться сообщение «Неверный формат».

**Фактический результат:** Форма отправляется, сообщение об ошибке не появляется.

**Приоритет:** Средний.

### Баг №2: Владелец из одной буквы проходит валидацию

**Сценарии:** NEG-PAY-HOLDER-ONE-CHAR-01, NEG-CREDIT-HOLDER-ONE-CHAR-01

**Описание:** Поле «Владелец» принимает значение из одной буквы (например, "I").

**Ожидаемый результат:** Под полем «Владелец» должно отображаться сообщение «Неверный формат».

**Фактический результат:** Форма отправляется, сообщение об ошибке не появляется.

**Приоритет:** Средний.

### Баг №3: Владелец на кириллице, с цифрами или спецсимволами проходит валидацию

**Сценарии:** NEG-PAY-HOLDER-CYRILLIC-01, NEG-PAY-HOLDER-DIGITS-01, NEG-PAY-HOLDER-SPECIAL-01, NEG-CREDIT-HOLDER-CYRILLIC-01, NEG-CREDIT-HOLDER-DIGITS-01, NEG-CREDIT-HOLDER-SPECIAL-01

**Описание:** Поле «Владелец» принимает значения «Иван Иванов», «Ivan123 Ivanov», «Ivan@#$ Ivanov» без сообщения об ошибке. Форма отправляется успешно.

**Ожидаемый результат:** Под полем «Владелец» должно отображаться сообщение «Неверный формат».

**Фактический результат:** Форма отправляется, сообщение об ошибке не появляется.

**Приоритет:** Средний.
