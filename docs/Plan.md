## 4. Риски при автоматизации

| Риск | Описание | Способ снижения |
|------|----------|-----------------|
| Изменение UI | Элементы формы могут меняться | Использовать устойчивые селекторы (placeholder, тексты лейблов) |
| Зависимость от внешнего сервиса | Payment-gate может быть недоступен | Использовать локальное окружение и симулятор из ТЗ |
| Баги приложения | Валидация поля «Владелец» неполная, уведомления не отображаются | Оформлять issue, не блокировать сборку падающими тестами |
