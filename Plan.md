### Заполнение формы записи

**Сценарий №4: Заполнение формы валидными данными**
| Элемент | Описание |
|---------|----------|
| **Уникальное имя** | fill_form_valid_data |
| **Входные данные** | Все поля заполнены валидными данными (имя на кириллице, номер телефона в формате +7XXXXXXXXXX, email в формате example@domain.com) |
| **Пример данных** | Имя: Иван Иванов, Телефон: +79001234567, Email: ivan@mail.ru |
| **Шаги** | 1. Открыть страницу профессии "Инженер по тестированию"<br>2. Прокрутить до формы записи<br>3. Заполнить поле "Имя" валидным значением<br>4. Заполнить поле "Телефон" валидным значением<br>5. Заполнить поле "Email" валидным значением<br>6. Нажать кнопку "Записаться" |
| **Ожидаемый результат** | Появляется уведомление об успешной отправке формы |

## 2. Перечень используемых инструментов

| Инструмент | Обоснование выбора |
|------------|-------------------|
| Java 11 | Язык написания автотестов, универсальность |
| JUnit 5 | Стандарт для модульного тестирования |
| Selenide | Упрощает UI-тесты, автоматическое ожидание |
| Allure | Наглядные отчёты |
| Gradle | Управление зависимостями и сборка |
| JavaFaker | Генерация тестовых данных |
| AssertJ | Утверждения в тестах |
| Selenium WebDriver | Работа с браузерами |
| GitHub Actions | CI для автоматического запуска тестов |

## 3. Перечень необходимых разрешений, данных и доступов

| № | Доступ | Необходимость |
|---|--------|---------------|
| 1 | Разрешение на тестирование формы записи | Для выполнения автотестов |
| 2 | Тестовые данные для формы (имена, телефоны, email) | Для заполнения формы |
| 3 | Доступ к странице профессии "Инженер по тестированию" | Публичный доступ есть |
| 4 | Доступ к системе аналитики для проверки отправки форм | Для проверки корректности отправки |
| 5 | Тестовый аккаунт в системе (если требуется) | Для проверки записи |

## 4. Риски при автоматизации

| Риск | Описание | Способ снижения |
|------|----------|-----------------|
| Изменения UI | Элементы формы могут меняться при обновлении сайта | Использовать устойчивые селекторы |
| Блокировка IP | Частые запросы могут привести к блокировке | Использовать тестовые данные, не отправлять формы реально |
| Изменение структуры | Страница профессии может изменить структуру | Периодически обновлять тесты |
| Требование капчи | Может потребоваться ввод капчи при отправке | Использовать тестовое окружение |
