## Общие рекомендации

1. Использовать устойчивые селекторы (data-attributes) для элементов формы
2. Согласовать с владельцами сайта возможность автоматизированного тестирования
3. Использовать тестовое окружение для запуска автотестов
4. Добавить тестовые данные для заполнения формы без реальной отправки
