# Отчёт о тестировании

## Краткое описание

Проведено автоматизированное тестирование функциональности оплаты и покупки в кредит на сайте http://localhost:8080. Протестированы позитивные и негативные сценарии заполнения формы с данными банковской карты. Проверка результатов выполнялась как через UI (уведомления), так и через запросы к БД (статусы операций).

## Общие рекомендации

1. Использовать устойчивые селекторы с data-атрибутами для элементов формы, чтобы снизить хрупкость тестов.
2. Добавить отдельные тестовые карты для проверки граничных случаев (нулевой CVC, месяц 00, год 00).
3. Настроить регулярный запуск автотестов в CI при каждом пуше.
4. Расширить проверки в БД: сверять сумму операции, а также связь `payment_entity` ↔ `order_entity`.
5. Исправить баг с сохранением DECLINED-операций — без него невозможно полноценно верифицировать негативные сценарии на уровне БД.
